# Synqra — UX and design-system audit
Date: 2026-10-17
Base revision: 664f429
Style references: Taskify PM and Mova dashboards (light canvas, framed workspace, compact sidebar with a project list, pill tabs, soft cards).

Before/after comparisons are in [`docs/ui-refresh/`](ui-refresh/).

## Findings and fixes

Severity: **High** breaks a flow or looks broken, **Medium** inconsistent with the design system or confusing, **Low** polish.

| # | Area | Finding | Severity | Fix |
| --- | --- | --- | --- | --- |
| 1 | Command palette | ⌘K opened an unstyled list (raw icons and text run together) until a Meetings or task-detail chunk happened to load, because its CSS lived in `workflow.css`, which only lazy routes imported. | High | Global feature CSS is imported up front in `main.jsx`; palette restyled (search row, grouped results, hints). |
| 2 | Notifications | Same root cause: the bell menu rendered as one unstyled line across the top of the page. | High | Same import fix; menu restyled as an anchored popover with unread dots. |
| 3 | Cascade order | Which stylesheet won depended on which page you opened first, so the same control could look different between sessions. | Medium | Deterministic import order; one final visual layer (`src/redesign.css`). |
| 4 | Sidebar project dropdown | The project picker opened a 380px panel floating over the page content, with large rows; the sidebar trigger itself was a 46px card. | High (reported) | Projects are listed in the sidebar with tinted marks (Mova/Taskify pattern). "All projects / Find project" opens a compact finder anchored to the sidebar width, with search, Escape and outside-click dismissal. |
| 5 | Account card | Clicking your name in the sidebar signed you out immediately, with no confirmation. | High | The card opens an account menu; Sign out is an explicit item. |
| 6 | Board "0" | The Board filter row showed a stray `0` (`{hasFilters && …}` rendered the number 0). | Medium | `hasFilters` is a boolean. |
| 7 | Create action naming | The same action was "Submit Review" (Overview, All Reviews), "Create Task" (My Work, Board) and "Submit new review" (⌘K), while the dialog says "Create task". | Medium | "New task" everywhere; dialog stays "Create task". |
| 8 | Page headings | Board had no page title (only a duplicate project dropdown); Overview used its own heading markup. | Medium | Board and Overview use the shared `PageHeading`; Board's duplicate project picker removed (the breadcrumb shows the project). |
| 9 | Dialogs | Title and description were ~40px apart (browser default margins, no preflight); New project led with a big icon while other form dialogs didn't; the Collaborator dialog had no header wrapper; assignee value was centered in its field. | Medium | One dialog anatomy: compact header, body, footer bar with actions aligned end. Icons only on confirm/success dialogs. Select labels left-aligned. |
| 10 | Task drawer | Section headings duplicated their only field label ("Description / Description", "Related meeting / Related meeting"). | Low | Field label kept for screen readers, hidden visually. |
| 11 | Mixed language | "ISI RAPAT", "TIM", "INVITE KE PROJECT", "email@contoh.com", Indonesian onboarding copy and Indonesian day/month names in the date picker, inside an English UI. | Medium | English throughout; date picker uses `en-US`. |
| 12 | Meeting templates | Four small text tiles under a long textarea; "Meeting notes" inserted the standup structure; "Recently used" always showed Blank Meeting regardless of use; picking a template silently overwrote notes. | High (reported) | Illustrated template gallery (8 templates) with a miniature preview of each structure, "In use" / "Last used" badges (persisted), a collapsible gallery and an inline "Replace your notes?" confirmation. |
| 13 | Meeting editor chrome | Title rendered as a bordered input, date showed two calendar icons, a separate "Draft" label duplicated the save state, and Writing / Review / Completed looked like clickable tabs. | Low | Borderless title, single date chip, one save-state pill, numbered stepper. |
| 14 | Tabs | Reports and Board used underline tabs with a heavy 3px active border. | Low | Segmented pill control (Mova pattern). |
| 15 | Mobile | Collaborator label overflowed its button; search was unreachable on mobile. | Medium | Icon-only Collaborator on narrow screens; search icon button opens ⌘K. |
| 16 | Kanban cards | Priority was a black dot plus grey text for every level. | Low | Coloured priority chips (Blocker red, Major amber, Minor blue). |

## Design-system changes

Documented in `design.md`: refreshed canvas/border tokens, radius and elevation scale, categorical tints (project marks and template art only), app frame and sidebar rules, dialog anatomy, segmented tabs, meeting template gallery, and copy rules.

## Verification

- `e2e/ui-audit.spec.js` and `e2e/core-flow.spec.js`: 35 passed in Chromium, including new tests for the sidebar project list and finder, the account menu, the template gallery and its overwrite protection, and styling of global surfaces before any lazy route loads (also guards the Board `0`).
- `npm test`: 17 passed, 1 skipped (the opt-in real-Worker test).
- `npm run build`: passed; CSS now ships as a single stylesheet.
- Not run here: the real-Worker browser flow (needs a local Worker with D1/R2) and Firefox/WebKit. Its selector for the collaborator dialog title was updated to "Invite collaborators".
